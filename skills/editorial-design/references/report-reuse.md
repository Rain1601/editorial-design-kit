# 报告内容迁移

沿用 report-content 的显式双语数据契约和 mountReportReader，按任务写内容；不要每份报告重写布局和交互。示例只是样稿，不作为事实或效果证据。

新增报告：稳定 report id；独立 section / figure / details id；明确范围、日期与来源；summary 指向本报告的章节；每张图有单位、范围和图注，所有图必须出现在正文。事实、建议和原创示例分别声明，缺失依据不编造。

已验证的内容差异：editorial-reading 三章一图、reading-continuity 两章两图、evidence-to-judgment 四章两图。第三份为“研究结论如何站得住”：长摘要、范围展开、六条带正负/零/缺失记录的图，以及三条记录的第二张图。它直接使用同一阅读器，没有专属 CSS。

复用检查：
1. Paper 与 Paper Night 使用同一 DOM，长标题和摘要自然换行。
2. 每张图的 chart/data 独立，单位、顺序、负值、0、null 保留；第二张图不能随第一张变化。
3. 换色保持坐标、details 和图表状态；来源面板内换色保持 open、query、selected excerpt 和内部滚动。
4. 关闭来源恢复原引用焦点与阅读坐标；从列表重新进入恢复同一报告记录，打开另一报告不复制前一份的模式或坐标。
5. 页面编号由报告身份在显式目录中的位置派生，不能所有报告固定显示 01；未知报告仍明确报错。

浏览器证据仅覆盖当前样稿、语言和视口。阅读会话仅保存标签页的阅读元数据；不声称通用 PDF 导出、实际研究质量或任意长文已经验收。来源 modal 打开状态仅在当前实例保留，重新导航不复原 modal。

## 动效与恢复

reader 的说明区使用 mountDetailsMotion；getState 保存逻辑展开状态，关闭动画未结束也不会保存为打开。语言重建恢复时不重播动画。图表／数据下划线只在用户选择时移动，每张图继续保存自己的表示模式。数值、缺项、来源与章内阅读偏移保持原契约。详见 [motion.md](motion.md)。
